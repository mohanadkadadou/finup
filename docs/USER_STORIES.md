# User stories

- As a user I upload a bank statement (PDF/CSV/XLSX) so my spending is analysed without manual entry.
- As a user I review and fix extracted rows before they count, so wrong data never reaches my dashboards.
- As a user I see who I paid most, where my money went and on which days I spend most.
- As a user I get rule-based tips to cut waste, with what-if savings clearly labelled as estimates.
- As a user I plan a purchase and see how long it takes and what cuts would speed it up.
- As a user I set savings goals and see a monthly plan and honest affordability.
- As a user I ask questions answered only from my confirmed transactions.
- As a user I use the app in Arabic (RTL) or English, installed on my phone.
- As a user I can reset my password, verify my email, export my data and delete my account.
