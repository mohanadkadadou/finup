# Demo script (5 minutes)

1. Register (or `npm run seed:demo` → `demo@finup.local`).
2. **Import** → _Load sample demo data_ (clearly labelled demo), or upload a CSV/XLSX/PDF statement; review flagged rows, confirm.
3. **Dashboard / Analytics:** income, expenses, categories, trends.
4. **Insights:** who you paid most, top categories, costliest days, weekday spend, saving tips.
5. **Purchase planner:** enter a price; see months needed and what cuts would close the gap.
6. **Goals:** create a goal; see the monthly plan and affordability.
7. **Assistant:** ask "where did my money go last month?" (works without an API key).
8. Switch language Arabic ⇄ English (RTL).
